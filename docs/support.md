# Suporte — Konaet Cover

## Como entrar no aplicativo

Na tela de acesso, toque em **Entrar no modo demonstração**. Não é necessário criar conta nem informar dados reais.

## Relatar um problema

Use o [rastreador público de issues](https://github.com/7dsolv/konaet-cover/issues/new/choose) para erros gerais e sugestões.

Vulnerabilidades de segurança devem ser comunicadas somente pelos [GitHub Security Advisories](https://github.com/7dsolv/konaet-cover/security/advisories/new), sem abrir uma issue pública.

## Privacidade

Leia a [política de privacidade](PRIVACY.md). A versão demonstrativa não contém anúncios, não exige cadastro e não coleta identificadores reais do dispositivo.

## Limites da versão alpha

O aplicativo é uma demonstração técnica: não movimenta dinheiro, não oferece seguro e não representa um serviço financeiro ou atuarial.
