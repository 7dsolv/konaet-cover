# Rascunho da ficha da loja — pt-BR

## Nome

Konaet Cover

## Descrição curta

Demonstração de proteção verificável e simulação de risco para dispositivos.

## Descrição completa

Konaet Cover é uma experiência técnica de proteção coletiva de dispositivos com decisões reconstruíveis. Explore uma interface em Jetpack Compose, pools demonstrativos, trilhas causais e um laboratório de risco reproduzível.

Esta versão é uma demonstração de pesquisa:

- funciona sem cadastro pelo modo demonstração;
- não movimenta dinheiro e não oferece seguro;
- não toma decisões financeiras ou atuariais;
- não utiliza identificadores reais de aparelhos;
- não envia dados pessoais para blockchain.

O projeto é aberto para estudo, auditoria e contribuições da comunidade.

## Notas da versão 0.1.0-alpha.1
