# Roadmap do Konaet Cover

O roadmap separa código existente de capacidades planejadas. Marcação concluída exige implementação, teste e documentação.

## Agora — fundação verificável

- [x] Estrutura de monorepo.
- [x] API NestJS com Prisma.
- [x] Motor de risco FastAPI reproduzível.
- [x] Contrato mínimo de checkpoint.
- [x] Protótipo Android com onboarding, autenticação demo e home.
- [x] CI para API, risco e contratos.
- [ ] Migrações Prisma versionadas e teste de integração com PostgreSQL.
- [ ] Autenticação real com hash de senha ou passkey.
- [ ] Wrapper Gradle e build Android reprodutível na CI.

## Próximo — fluxos completos

- [ ] Registro e comprovação criptográfica do dispositivo.
- [ ] Ciclo completo de pool e cobertura.
- [ ] Upload, hash, revisão e retenção de evidências.
- [ ] Máquina de estados de sinistros com autorização por função.
- [ ] Merkle tree e geração de checkpoint a partir de eventos causais.
- [ ] Painel administrativo mínimo.
- [ ] Observabilidade, rate limiting e trilha de auditoria operacional.

## Futuro — validação e produção

- [ ] Dados autorizados e validação independente do modelo de risco.
- [ ] Threat model completo e teste de invasão.
- [ ] Auditoria externa dos contratos.
- [ ] Avaliação LGPD e regulatória.
- [ ] Política de retenção e exclusão comprovável.
- [ ] Build Android assinado e preparação para distribuição.

Nenhum item futuro implica autorização para operar seguro ou movimentar recursos reais.
