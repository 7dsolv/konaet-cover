# Política de Privacidade — Konaet Cover Alpha

Última atualização: 30 de agosto de 2026.

## Escopo

O Konaet Cover Alpha é uma demonstração técnica e de pesquisa. Ele não oferece seguro, não movimenta dinheiro e não deve ser usado para decisões financeiras, atuariais ou regulatórias.

## Dados na versão pública de demonstração

O modo demonstração funciona localmente no aparelho e não exige cadastro. Esta versão:

- não inclui publicidade ou SDK de analytics;
- não solicita acesso à câmera, localização, contatos, arquivos, telefone ou identificadores do dispositivo;
- não coloca dados pessoais em blockchain;
- não vende nem compartilha dados pessoais.

O aplicativo possui código experimental para conexão HTTPS com uma API. Se uma instância de backend for configurada e o usuário optar por autenticar, endereço de e-mail, credenciais de acesso e dados enviados voluntariamente poderão ser processados pela instância escolhida. Uma implantação pública deverá publicar seus próprios termos, finalidade, retenção, base legal e canal de exclusão antes de receber dados reais.

## Segurança

Tokens e credenciais não são gravados no repositório. Vulnerabilidades devem ser relatadas de forma privada pelos [GitHub Security Advisories](https://github.com/7dsolv/konaet-cover/security/advisories/new).

## Crianças

A demonstração não é direcionada a crianças e não foi projetada para coletar dados de menores.

## Alterações

Esta política será atualizada antes de qualquer mudança material na coleta ou no tratamento de dados. O histórico fica disponível no Git.
